ALDUIN X — LIVE2D + AI + VOICE EDITION

Запуск: GitHub Pages или локально через HTTP-сервер.

Добавлено в этой версии:
- Live2D Cubism 3/4 с ZIP/папкой модели.
- Встроенная модель Miara.
- AI рядом с Live2D.
- Подключение Gemini, Groq, OpenAI, DeepSeek, Grok, OpenRouter и других OpenAI-compatible API.
- AI может управлять эмоциями и движениями Live2D.
- Новый бесплатный голосовой движок через Web Speech API браузера.
- Русский и English.
- Несколько стилей: Anime Soft, Anime Cute, Anime Energetic, Anime Calm.
- Выбор установленного голоса устройства.
- Скорость и высота голоса.
- Тест/стоп голоса.
- Ответы AI могут автоматически озвучиваться.
- Во время речи Live2D получает простую lip-sync анимацию ParamMouthOpenY.

Важно про голос:
Голос не требует API-ключа и не отправляет текст в отдельный TTS-сервис. Используются голоса, которые доступны самому браузеру/Android. Поэтому список голосов зависит от устройства. Стиль Anime меняет скорость/высоту, а выбор конкретного женского голоса делается через список голосов устройства.

После обновления GitHub Pages:
1. Загрузить файлы новой версии.
2. Убедиться, что model3/moc3/texture файлы находятся в репозитории.
3. Открыть сайт и один раз полностью перезагрузить страницу.
4. В Live2D → Голос ALDUIN выбрать язык, стиль и голос.
